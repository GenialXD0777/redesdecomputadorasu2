Manual Didáctico: Conceptos Clave

1. Modelo OSI vs. Modelo TCP/IP

El Modelo OSI (Open Systems Interconnection) es un estándar teórico de 7 capas creado por la ISO. El Modelo TCP/IP es un modelo práctico de 4 capas con el que funciona el Internet real.

Capa OSI (7) Capa TCP/IP Función & Protocolos
7. AplicaciónAplicaciónHTTP, HTTPS, DNS, DHCP, FTP
6. PresentaciónFormato, cifrado TLS/SSL, compresión
5. SesiónControl de diálogo entre aplicaciones
4. TransporteTransporteTCP (confiable), UDP (datagramas rápidos)
3. RedInternetIP (IPv4/IPv6), Enrutamiento, Routers
2. Enlace de DatosAcceso a RedTramas, direcciones MAC, Switches
1. FísicaSeñales eléctricas/ópticas, cables, bits
2. ¿Qué diferencia hay entre IEEE 802.2 y IEEE 802.11?

En el estándar IEEE 802, la Capa 2 (Enlace de Datos) se divide en dos subcapas: LLC (arriba) y MAC (abajo).

IEEE 802.2 (LLC - Logical Link Control)

Es la subcapa superior de Enlace. Es independiente del medio físico. Proporciona una interfaz uniforme para que la capa de Red (IP) se comunique con cualquier medio (Ethernet, Wi-Fi o Token Ring).

IEEE 802.11 (Wi-Fi / WLAN)

Define la Capa Física (Radiofrecuencias 2.4/5/6 GHz) y la subcapa MAC inalámbrica (uso de CSMA/CA para evitar colisiones por aire y tramas Wi-Fi).

💡 Regla Nemotécnica: 802.2 es el software de control de enlace lógico genérico; 802.11 es la radio y el protocolo de acceso inalámbrico físico (Wi-Fi).
