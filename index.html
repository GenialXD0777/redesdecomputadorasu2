Manual Didáctico: Conceptos Clave

1. Modelo OSI vs. Modelo TCP/IP

El Modelo OSI (Open Systems Interconnection) es un estándar teórico de 7 capas creado por la ISO para estandarizar la arquitectura de red abierta. Por otro lado, el Modelo TCP/IP es un modelo práctico de 4 capas (o 5 según la literatura moderna) sobre el que opera el Internet moderno.

2. ¿Qué diferencia hay entre IEEE 802.2 y IEEE 802.11?

En la familia IEEE 802, la Capa 2 (Enlace de Datos) se divide en dos subcapas: LLC (Logical Link Control) y MAC (Media Access Control).

IEEE 802.2 (Subcapa LLC)

Es el Control de Enlace Lógico. Es independiente del medio físico. Proporciona una interfaz uniforme para que los protocolos de red (como IP) puedan comunicarse con cualquier tecnología de nivel inferior (Ethernet 802.3, Wi-Fi 802.11 o Token Ring).

IEEE 802.11 (Wi-Fi / WLAN)

Especifica la Capa Física (Radiofrecuencia 2.4/5/6 GHz) y la Subcapa MAC Inalámbrica. Define métodos de acceso como CSMA/CA (prevención de colisiones por radio), autenticación WPA y tramas de baliza (Beacon frames).

💡 Regla Nemotécnica: IEEE 802.2 es el software de enlace genérico (LLC) común; IEEE 802.11 es la implementación física y de acceso inalámbrico concreta (Wi-Fi).
